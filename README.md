## 加内存还是升套餐？算一遍就清楚了

Evoxt 允许单项加购，但相邻档位之间的差价，通常比单项买同样的资源更便宜。把差价和加购价放一起看：

VM-1（1 核 2GB，$5.99）升到 VM-1.5（2 核 2GB，$6.95），多付 $0.96 拿到 1 个核。单独加 1 核是 $3/月。升档便宜三分之二。

VM-3（4 核 4GB，$14.99）升到 VM-4（4 核 8GB，$23.99），多付 $9 拿到 4GB 内存、30GB 硬盘和 1TB 流量。单加 4GB 内存 $8 加 1TB 流量 $3，合计 $11。

结论很干脆：想加资源，先看上一档的差价，绝大多数情况上升档更划算。单项加购真正的用处是补一个很具体的短板，比如你已经跑满 VM-4 的 8GB 内存但核数够用，加 2GB 内存花 $4 比跳到 VM-6 花 $6 更省，不过 VM-6 只给 8 核配 8GB，核多了内存没多，跳过去反而更尴尬。

额外 IPv4 需要单独提醒一下：$3 一个月等于一年 $36，比 VM-0.5 一整年的费用还高。除非你确实要跑多 IP 的业务，别顺手勾上。

## 买之前必须知道的几条限制

**不支持支付宝和微信。** 官网列出的支付方式是信用卡、借记卡、PayPal、Bitcoin 和 USDt（Tron 网络）。国内用户得有一张能付外币的卡，或者愿意走加密货币。这一条会直接挡掉一部分人，早点确认比下单时卡住好。

**香港和大阪不等于中国大陆优化线路。** 定价页把这两地单列为 Premium Network，差别写在流量额度上，页面没有给出三网优化或 CN2 之类的说明。如果你的访客主要在国内，按普通国际线路做预期，别把"Premium"这个名字理解成对大陆访问的优化。

**换 IP 的政策官网没有公开写明。** 套餐含 1 个 IPv4 和 1 个 IPv6，额外 IPv4 是 $3/月，但页面没写被封之后多久能免费换一次、超出怎么收费。这一条我查不到确切条款，不想替它编一个数字，你在下单前直接问客服更稳。

**流量超了会不会停机，页面也没写清楚。** 定价页给了按 TB 购买额外流量的入口，说明超量之后是可以通过付费补上的，但停机还是限速没有明确说明。

**备份是每周一次。** 基础备份够用来回滚一次误操作，如果你的站每天都在变，靠周备份会丢一周数据，需要更密的备份得另买付费计划，价格按硬盘容量算。
